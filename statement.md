# Project Statement

## Problem Statement

Calculating Body Mass Index (BMI) manually can be inconvenient and may result in calculation errors. This project provides a simple Python-based application that automatically calculates BMI and displays the corresponding BMI category.

## Scope of the Project

The project focuses on collecting the user's basic information, calculating BMI using height and weight, identifying the BMI category, and providing a basic health suggestion. The application also allows multiple BMI calculations in one session.

## Target Users

The project is intended for students, beginners, and general users who want to calculate their BMI using a simple command-line application.

## High-Level Features

* User information input
* BMI calculation
* BMI category identification
* Basic health suggestion
* Result display
* Multiple BMI calculations
* Basic input validation
